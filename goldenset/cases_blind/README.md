# 블라인드 배포본 (B01~B20) — 1차 라벨링 시점 기록

라벨러에게 실제로 배포된 사본입니다. 정답 필드를 제거하고 사례 ID를 `B01`~`B20`으로
치환한 상태이며, **1차 라벨링 당시의 본문 그대로 보존합니다.**

## ⚠️ `cases/`와 내용이 다른 파일이 2건 있습니다

| 블라인드 | 원본 | 차이 |
|---|---|---|
| `B16.md` | `cases/case_010.md` | 입력에 없는 비교 기준("앞선 조정 국면 대비") **삭제 전** |
| `B18.md` | `cases/case_008.md` | 서술문 수치를 근사값으로 낮추기 **전** |

이 2건은 pass로 설계했으나 출제자 작성 오류로 결함이 들어갔고, 블라인드 라벨링에서
2인이 fail로 잡아냈습니다. 라벨을 설계에 맞추는 대신 **본문을 고치고 재라벨**했습니다.

**여기 파일을 수정본으로 덮어쓰지 마세요.** 이 두 파일은 "라벨러가 그때 무엇을 보고
fail로 판정했는가"를 증명하는 기록입니다. 덮어쓰면 그 근거가 사라집니다.

재라벨링에 쓰인 수정본은 `dist_relabel/`에 있습니다 (`R02`=case_010, `R03`=case_008).
