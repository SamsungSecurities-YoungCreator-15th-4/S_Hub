| 항목 | 내용 |

## 2. VaR / CVaR

| 항목 | 값 |
|---|---|
| 신뢰수준 | 99% |
| 신뢰구간 수준 | 90% |
| 산출 방법 | 역사적 시뮬레이션 |
| 관측 구간 | 1,250 영업일 |
| 구간 산출 | VaR 순서통계량 · CVaR 부트스트랩(n=1,000) |

| 지표 | 1일 | 10일 |
|---|---|---|
| VaR (비율) | 0.00701000 | 0.02216757 |
| VaR (KRW) | 37,503,500 | 118,596,480 |
| VaR 90% 신뢰구간 (KRW) | 32,207,000 ~ 36,326,500 | 101,847,477 ~ 114,874,479 |
| CVaR (비율) | 0.00889000 | 0.02811265 |
| CVaR (KRW) | 47,561,500 | 150,402,669 |
| CVaR 90% 신뢰구간 (KRW) | 40,713,500 ~ 54,463,000 | 128,747,392 ~ 172,227,128 |

| 해석 | 내용 |
|---|---|
| 1일 VaR | 약 3,750만원 |
| 1일 CVaR | 약 4,760만원 |
| 10일 환산 | 1일 값 × √10 근사. 신뢰구간 경계도 동일 규약 적용 |
| **환산 한계** | 독립동일분포 가정에 근거하므로 변동성 군집 구간에서는 **실제 손실이 환산값을 초과할 수 있습니다** |

> "위험값은 표본에서 산출한 추정량이므로 확정된 값으로 서술하지 아니한다."
